# 1.4.71 第一阶段：可靠性与决策记录

## 已实现

- 识别请求和心跳恢复带代际校验，离开对局后丢弃迟到结果。
- 胜率接口不阻塞 OCR；没有统计也可显示已识别卡片。
- 海克斯差值使用原始胜率减英雄基准，单位为百分点；不再将混合推荐分伪装为胜率。
- 强化资料页折叠式本地选择档案，保留最近 120 次完整识别。只有新增强化 ID 与实际选项匹配才确认选择；否则保持未确认。
- 备战席换人按钮显示英雄类别数量变化，浮窗悬停显示同样说明。不是战力或胜率预测。
- 浏览战绩或展开详情时，后台刷新保留现有内容；更新结果写缓存，点击提示再刷新。查询他人期间禁止本人后台刷新接管页面。
