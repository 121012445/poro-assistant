# 同类英雄进步报告（1.4.74）

1.4.74 将下述旧版的“同英雄”分组替换为“同主类别”：战士、刺客、法师、射手、坦克、辅助。取静态资料 tags 中首个有效标签，每场只计一次；缺少标签的英雄不猜测。新增类别选择器，默认选择样本最多的分组。同队列、5 分钟时长区间和至少 6 场的门槛保留。跨英雄原始伤害等指标仅作描述性参考，不能据此认定个人进步。旧 schema 1 目标保留但暂停，新目标使用 schema 2，不能混算。

以下为初版规则记录，其中同英雄条件由上述类别条件替代。

入口：首页 → 持续提升中心。替换原有混合模式、固定死亡阈值的训练目标。

- 对当前已加载战绩按英雄、队列、5 分钟时长区间分组，选择样本最多的一组（同数优先最近）。
- 至少 6 场，每期取相邻的 3–5 场，比较较早期和近期；场均死亡取均值，伤转为总英雄伤害/总金币，DPM 为总英雄伤害/总分钟。
- 缺失关键指标、自定义对局、少于 5 分钟的对局不参与。同场去重，国服英雄 ID 归一化。
- 点击开始跟踪才保存目标，默认以近期场均死亡降低约 10% 为目标；不声称能判断“无效死亡”。
- 仅目标创建之后开始、满足原分组条件的前 5 场进入跟踪。按玩家 PUUID 存本地配置，重复查询不重复累计，已观察对局离开查询窗口仍保留。
- 跟踪仍显示伤转变化，死亡目标达成不代表整体变强，不作因果推断。

限制：只使用已加载的战绩，未控制版本、位置、阵容、强化，样本很小。旧缓存缺字段完整性标志时只能校验现有数值。目标跟踪在读取该玩家的报告时更新，不后台抓取所有历史。

验证：`node test_progress_report.js` 与 `npm test`。真实新对局与长期跟踪仍需要使用验证。
