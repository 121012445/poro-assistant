选人与对局辅助

备战区助手（大乱斗 / 海斗）

列出当前能换到的英雄，点一下就发起，不做本地等待：备选（抽卡池）里的英雄开局就固定、从来没有冷却，点了就是瞬换；备战席里的英雄绝大多数也能立即换到 —— 只有刚被骰子重随进备战席的那一个带 3 秒保护期（官方 14.13 起，防队友抢板凳）。助手一律先出手问服务器，被拒了才把它当作保护期、精确等到结束自动再换。你不需要盯着倒计时，也不需要反复点。开启开关后还会弹出倒计时提醒。

⚠ 那 3 秒保护期由服务器判定，本助手无法也不尝试缩短它，只是把"等"和"重试"从你身上挪走；按钮只列出服务器当前允许你选择的英雄。使用第三方辅助工具仍可能违反游戏规则，请自行评估账号风险。

已关闭

选人保底（防超时随机）

轮到你选人时，如果你还没悬停任何英雄，助手替你先悬停一个，避免倒计时结束时被随机分配。补的只是悬停，不会锁定，你之后随时能换。

英雄来源：优先用「自动 BP」里配置的出战英雄池；池子为空时按你客户端里的英雄熟练度取前 10，不配置也能用。

已关闭

⚠ 补位只写你本机客户端，不发聊天、不改队友。开启「超时锁定」后助手会替你把悬停的英雄锁死，请确认池子里的顺序是你愿意接受的结果。

设置与数据

软件更新 有新版本

从本项目的 GitHub 发布页检查新版本。只在你点击后下载，下载完成会校验 sha256 与文件大小，再由你点击安装；不会自动安装。

合规模式（默认关闭）

开启后进入只读模式：自动化与对客户端的写入操作全部停用。Poro 不注入游戏进程、不读取游戏内存；关闭前请自行确认所在服务器规则。
