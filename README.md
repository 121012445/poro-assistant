# Poro

Poro 是一款面向《英雄联盟》玩家的 Windows 桌面助手，基于 Electron 构建。它整合玩家档案、近期战绩、实时对局、海克斯大乱斗强化推荐、备战区工具和赛后复盘，并尽量让所有自动化功能保持透明、可关闭。

> 本项目是社区开源工具，与 Riot Games、腾讯游戏及其关联公司没有官方关系。“League of Legends”“英雄联盟”及相关素材归各自权利人所有。

## 功能

- 玩家档案：近期胜率、模式统计、常用英雄、常一起玩的队友和趣味数据。
- 战绩查询：最多加载近 100 场，展示 KDA、伤害、承伤、经济效率和表现标签。
- 实时对局：两队十人信息、近期表现、阵容结构与模式适配分析。
- 海克斯大乱斗：按英雄、轮次、样本量与组合数据推荐三选一强化。
- 游戏内悬浮层：强化选择提示、备战区英雄信息及自适应分辨率定位。
- 工具箱：客户端窗口修复、游戏设置锁定、自动符文、KDA 简报等。
- 赛后复盘：按模式生成表现评分、关键节点和可选的 AI 分析。
- 国内与 Riot 平台路由：根据客户端区域选择可用的数据接口。

## 技术栈

- Electron 44
- 原生 Node.js / JavaScript / CSS
- League Client Update API（LCU）
- Live Client Data API
- CommunityDragon / Data Dragon 公共静态数据
- Windows OCR、Win32 窗口与输入接口

## 运行要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 或更高版本（Electron 44 已不再支持 Windows 7 / 8 / 8.1） |
| 架构 | 64 位（x64）。目前不提供 32 位安装包 |
| 权限 | **需要管理员权限**，详见下节 |

### 关于管理员权限

`Poro.exe` 内置的清单要求以管理员身份运行，启动时 Windows 会弹出 UAC 提示，请选择「是」。
需要提权的原因：

- 需要写入英雄联盟客户端的 `Config` 目录（国服 WeGame 版本的该目录位于 `Program Files` 下）；
- 国服客户端通常也以管理员权限运行，读取其进程信息需要同级权限。

**如果无法提权**（标准用户账户、UAC 被组策略关闭、公司电脑限制提权等），
正式版将无法启动，表现为双击后没有任何反应。这类闪退**不会**产生运行日志
（进程根本没被创建），但安装时的自检报告会指出原因 —— 见「遇到闪退」。
这种情况请改用下面的「受限版」。

### 两个安装包

同一版本提供两个安装包，按账户权限选择：

| 安装包 | 权限要求 | 功能 |
| --- | --- | --- |
| `Poro-Setup-<版本>.exe` | **需要管理员权限** | 完整 |
| `Poro-Setup-<版本>-limited.exe` | 不需要 | 除「游戏内热键」「聊天预填」外均可用 |

受限版少这两个功能的原因：国服客户端以管理员身份运行，而未提权的进程无法向更高权限的
进程注入按键（Windows 的 UIPI 限制），与 Poro 自身的实现无关。
除此之外（战绩、档案、实时对局、强化推荐、悬浮层、设置锁定）两者行为一致。

两个包共用同一份配置与数据目录，可以互相覆盖安装；同一版本装其中一个即可。
应用启动时会在日志与诊断页标注自己是否以管理员运行，便于确认装的是哪一个。

## 遇到闪退

按顺序看两个日志文件 —— 它们回答的是不同的问题。

### 第一步：安装期自检报告（一定存在）

```
%APPDATA%\poro-assistant\install-check.log
```

这份报告在**安装完成时**就写好了，与程序能否启动无关 —— 只要装过就一定在。
它记录安装时的环境并直接给出结论：

| 字段 | 说明 |
| --- | --- |
| 在管理员组 | 账户本身是否属于 Administrators 组（决定正式版能否启动） |
| 安装器令牌 | 这次安装是否以管理员身份运行 |
| UAC (EnableLUA) / 提权提示策略 | UAC 是否开启、提权时是弹框还是要求输入密码 |
| 程序本体 | 安装目录里的 `Poro.exe` 是否真的落地了 |
| crash.log 已存在 | 程序此前是否成功启动过 |
| 结论 | 依据以上各项给出「预计可以正常启动」或「请改用受限版」等提示 |

若结论判定为「无法启动」，安装完成时也会弹框告知。

### 第二步：运行日志（只有程序成功启动过才有）

```
%APPDATA%\poro-assistant\crash.log
```

- **文件不存在** → 程序从未启动。请对照上一步的自检报告：多半是权限或系统版本问题
  （见「运行要求」）—— 这类闪退进程根本没被创建，所以不会有运行日志。
- **文件存在** → 程序起来了，请把整个文件发给维护者。启动行 `=== APP START ===` 会带上
  系统版本、架构、内存与 Electron/Chromium 版本，能直接定位大部分环境差异；崩溃时还会记录
  `[FATAL 阶段]`、`[GPU]` 特性状态。也可以在应用内「诊断」页一键导出诊断包。

> 反馈问题时，把整个 `%APPDATA%\poro-assistant` 文件夹打包发回来最省事。

## 本地开发

要求：Windows 10/11、Node.js 20+、npm。

```bash
npm install
npm start
```

运行测试：

```bash
npm test
```

生成 Windows 安装包：

```bash
npm run build          # 正式版（要求管理员权限），产物在 dist/
npm run build:limited  # 受限版（不提权），产物在 dist-limited/
npm run build:all      # 两个都构建
```

两个包的差别只有 PE manifest 的权限要求与输出目录，由 `electron-builder.limited.js` 覆盖，
`test_limited_build.js` 会守住"只允许差这三处"，避免两边配置漂移。

构建产物位于 `dist/` 与 `dist-limited/`，这两个目录都不会提交到 Git。

## 数据与隐私

- Poro 只在本机读取已登录英雄联盟客户端提供的会话与对局数据。
- LCU/SGP 临时令牌只保存在内存中，不写入仓库。
- AI 复盘为可选功能，API Key 使用 Electron `safeStorage` 加密后保存在用户目录。
- `userData`、日志、缓存、安装包与个人配置均已从版本控制中排除。

## 使用风险

第三方工具是否被允许取决于所在服务器的规则及其后续变化。使用自动化、输入模拟或游戏内悬浮功能前，请自行确认服务器规则并评估账号风险。项目提供合规模式用于关闭写入和自动化能力。
